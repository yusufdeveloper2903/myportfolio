## Задача

Предыдущее портфолио было одной страницей на Vue 2: контент зашит в шаблоны, нет SEO, нет
возможности публиковать кейсы и статьи, а сборка перестала работать на современном Node.

## Подход

- **Статическая генерация на Nuxt 4** — каждая страница заранее рендерится в HTML, поэтому открывается мгновенно и полностью индексируется.
- **Контент как данные** — проекты, статьи и опыт хранятся в Markdown/YAML и валидируются Zod-схемами в Nuxt Content. Новый кейс не требует правок компонентов.
- **Три языка** — английский, узбекский и русский: маршруты с префиксом языка, теги `hreflang` и английский фолбэк для непереведённых материалов.
- **Дизайн-система** — семантические цветовые токены поверх Tailwind CSS v4, автоматическая светлая/тёмная тема и анимации с учётом reduced-motion.
- **Клавиатура прежде всего** — меню команд `⌘K` для перехода к любой странице, проекту или действию.

## Архитектура

```txt
content/<locale>/{projects,blog,experience}  →  типизированные коллекции
app/composables/useLocalizedContent.ts       →  запросы с языковым фолбэком
app/pages/*                                  →  загрузка данных, сборка секций
app/components/{home,project,blog,site,ui}   →  презентационные компоненты
```

## Результат

Быстрый, доступный сайт, который легко поддерживать: новый проект — это один Markdown-файл.
