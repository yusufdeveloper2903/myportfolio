> Коммерческий продукт — исходный код и скриншоты закрыты.

## Задача

Диспетчеры одновременно управляют сотнями грузовиков. Им нужны живые позиции, быстрая связь с водителями и дашборды с телеметрией за годы — и интерфейс должен оставаться мгновенным при любом объёме данных.

## Моя роль

Руковожу frontend-разработкой: архитектурные решения, code review, работа над производительностью и выпуск фич вместе с backend- и product-командами.

## Архитектура и решения

- **Real-time слой** — WebSocket-потоки для живых GPS-позиций и статусов, WebRTC для диспетчерских звонков, event-driven UI, обновляющий только изменившееся.
- **Карты** — живое отслеживание на HERE Maps / Leaflet с кластеризацией для больших автопарков.
- **Производительность** — виртуализация таблиц на 10 000+ строк, LTTB-даунсэмплинг графиков временных рядов, code-splitting и lazy loading.
- **Данные** — TanStack Query для серверного состояния и кэша, Zustand для клиентского.
- **Поддерживаемость** — Feature-Sliced Design, строгий TypeScript, Vitest и Playwright в CI.

## Результат

Платформа, которая ощущается нативной даже на больших объёмах данных, и кодовая база, в которую новые фичи добавляются без затрагивания соседних модулей.
